2. Key Mathematical Findings:
-----------------------------
- Elliptic Envelope achieves an exceptional 0.9884 ROC-AUC and 91.6% Recall,
  demonstrating that anomalies are primarily driven by covariance contradictions
  between otherwise correlated features (e.g. high CGPA with critical attendance deficit).
- DBSCAN noise detection achieves the highest precision (93.9%), meaning almost any point
  falling into isolated spatial noise is a confirmed true anomaly.
- Isolation Forest provides linear O(n log n) scaling across all 35,000 students,
  isolating 93.1% ROC-AUC without quadratic distance matrices.
